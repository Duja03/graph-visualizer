### Project Setup

#### Web Application

1. Install NVM (Node Version Manager)
2. Use NVM to install NPM 22.12.0
   - Run `nvm list available`
   - Run `nvm install 22.12.0`
   - Run `nvm use 22.12.0`
3. Run `npm install`

### Style Setup
Import ```code-style.xml``` into your IDE of choice.
